What the full check looks at

Your data

Supabase tables readable without login (Row Level Security off), public storage buckets and files, open Firebase Realtime Database / Firestore.

Your keys

Secret keys and secret-looking VITE_ / NEXT_PUBLIC_ / REACT_APP_ variables in your bundles, window.__ENV__ dumps, exposed .env and .git.

Your login

Open sign-ups, email confirmation turned off, anonymous sign-ins, admin pages listed in your app, missing rate-limit signals on login endpoints.

Leftovers

Debug endpoints, GraphQL introspection, Swagger docs, server-status pages, stack traces, source maps, and library versions with known vulnerabilities.

How it works

  1. Request: give us your app's URL and confirm you own it.
  2. Scan: our scanner makes a limited number of read-only requests (it never writes, deletes or signs up, and never reads more than one row per table; row contents are thrown away).
  3. Report: you get a graded HTML report with what each issue means, why it matters, and a copy-paste fix prompt for Lovable, Bolt or Cursor.

FAQ

Is it really free?

Yes. During launch both the key checker and the full scan are free. If we ever add paid options, anything you already received stays free.

Does the key checker upload my code?

No. The detection runs in JavaScript on your device, and the page's security policy blocks it from sending your text anywhere. Only anonymous counts (for example "a check was run") are recorded, and not even those if your browser sends Do Not Track or Global Privacy Control.

Will the full scan break or change my app?

No. It only uses read requests (GET/HEAD/OPTIONS), waits between requests, reads at most one row per table and immediately discards the contents, and never calls your server functions, signs up, or logs in.

Why do you need me to confirm I own the app?

Scanning someone else's app without permission can be illegal. We only scan apps whose owner asked us to.

My Supabase anon key showed up. Is that bad?

No. The anon/publishable key is meant to be public. It's only dangerous if Row Level Security is off on a table, which is what the full scan checks.

Is this a penetration test or a guarantee?

No. It's an automated check for the most common mistakes in AI-built apps. A clean report does not guarantee your app is secure.

Can I use it from Cursor or Claude Code?

A local MCP server is in development, so your AI coding assistant can run the same checks. Ask us if you'd like early access.
